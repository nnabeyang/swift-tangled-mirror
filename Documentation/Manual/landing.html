tng CLI manual

Use tng to work with Tangled repositories, issues, pull requests, artifacts, Spindle pipelines, and repository CI secrets.

Installation

On an Apple Silicon Mac running macOS 15 or later:

brew tap nnabeyang/tap \
  https://tangled.org/nnabeyang.tngl.sh/homebrew-tap
brew install nnabeyang/tap/tng

To build from source on macOS or Linux, clone the repository and run ./install.sh.

Quick start

tng --version
tng auth login YOUR_ATPROTO_HANDLE
tng auth status
tng repo view OWNER/REPOSITORY

Public read commands do not require authentication. Commands that create or change Tangled records use your AT Protocol OAuth session.

Finding help

tng --help
tng repo --help
tng pr create --help
tng capabilities --json

Most repository-aware commands can infer the repository from the current Git origin. Use an explicit repository argument or --repo when you need to target another repository.

Terminal output

On macOS and Linux, terminal output experimentally renders human-readable Markdown, tables, and details with width-aware wrapping and optional ANSI styling. OSC-8 hyperlinks are disabled. Piped and redirected output stays unchanged. Use --json when scripts or agents need a stable, structured result.

For terminal-style output, tng repo view, tng issue view, tng pr view, and tng pr diff use the pager configured by TNG_PAGER or PAGER. TNG_PAGER takes precedence, including when set to an empty value. If neither variable is set, tng uses less by default. An empty selected value, cat, or TERM=dumb disables paging. If the selected pager is unavailable, tng warns and writes the output directly. A pager that fails after starting produces a warning without changing the command's exit status or repeating potentially partial output.

  • TNG_PAGER sets the pager command and takes precedence over PAGER; an empty value disables paging.
  • PAGER sets the pager command when TNG_PAGER is not set; an empty value disables paging. If neither pager variable is set, tng uses less.
  • TNG_FORCE_TTY forces terminal-style output and can specify a column count or percentage.
  • TNG_MDWIDTH limits the width available to width-aware Markdown rendering.
  • NO_COLOR or CLICOLOR=0 disables ANSI styling.
  • CLICOLOR_FORCE forces ANSI styling when no color-disable setting is active.

JSON, list, raw, binary, and streaming output is not sent to a pager. JSON, raw, binary, and streaming output is not decorated by these settings.
