Install and start

On Apple Silicon macOS 15 or later:

brew tap nnabeyang/tap https://tangled.org/nnabeyang.tngl.sh/homebrew-tap
brew install nnabeyang/tap/tng

Then inspect a repository or open the built-in help:

tng auth login YOUR_ATPROTO_HANDLE
tng repo view OWNER/REPOSITORY
tng --help
